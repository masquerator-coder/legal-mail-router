### 履职申请类文书专属分析流程

> 本流程适用于**履职申请类文书**：申请人要求行政机关查处违法行为、履行保护人身权、财产权等法定职责（《行政诉讼法》第四十七条＋国信发〔2017〕19号第十二条）。文书性质识别与入口分流已在上游完成，本流程直接进入审核。
> 〔审核顺序〕**审核流程（实体审核 → 案卷审核）→ 风险与建议 → 答复文本审核与标红修改稿**，依次执行，不得跳步。
> 〔体例标注〕〔明确规定〕＝规范明确、几无裁量空间；〔存在争议〕＝规范或裁判尺度不统一，须个案权衡；〔审核动作〕＝本条应执行的核对／留痕动作。
> 文中 `{today}` 为占位符，审核时替换为**审核当日日期**。

---

#### 一、审核流程

##### （一）实体审核要点

###### 〔审核动作〕1. 行政程序：两个月履行或答复

- 法律、法规对履职期限有规定的从其规定；**没有具体程序和期限规定的，应当在接到申请之日起两个月内履行或者答复**（国信发〔2017〕19号第十二条第二款）。〔明确规定〕
- 对欠缺形式要件的申请可要求补正（同条第三款）。
- 〔审核动作〕对照当前日期 `{today}` 计算：**收到申请日、两个月届满日、实际剩余／逾期天数**。**若已超期，须明确标注逾期天数及法律后果**（构成不履行法定职责）。

###### 〔审核动作〕2. 行政诉讼衔接

- 《行政诉讼法》第四十七条第一款：申请行政机关履行保护人身权、财产权等合法权益的法定职责，行政机关接到申请之日起**两个月内不履行**的，可以提起诉讼；紧急情况下请求履职而行政机关不履行的，起诉**不受两个月期限限制**。
- 法释〔2018〕1号**第六十六条**：对不履行法定职责提起诉讼的，应当自**履行期限届满之日起六个月内**提出。〔明确规定〕
- 该解释**第十二条第五项**：为维护自身合法权益向行政机关投诉、具有处理投诉职责的行政机关作出或者未作出处理的，投诉人具有原告资格——**公益性投诉**（如以监督执法为目的的举报）原则上不具有诉权。〔明确规定（个案认定存在裁量）〕

###### 〔审核动作〕3. 行政复议衔接：复议前置（2024年起重大变化）

- 《行政复议法》（2023年修订，主席令第九号，2024年1月1日施行）**第十一条第十一项**：申请行政机关履行保护人身权利、财产权利、受教育权利等合法权益的法定职责，行政机关拒绝履行、未依法履行或者不予答复的，可以申请行政复议。
- 该法**第二十三条第一款第三项**：认为行政机关存在第十一条规定的未履行法定职责情形的，**应当先申请行政复议**。〔复议前置〕直接起诉的，法院将裁定不予立案或驳回起诉（法释〔2018〕1号第六十九条第一款第五项）。
- **申请期限**：一般自知道或者应当知道行政行为之日起**六十日**（第二十条第一款）；未告知复议权利的最长不超过知道行为内容之日起**一年**（第二十条第三款）。
- 〔审核动作〕履职答复文书中是否**书面告知先行申请行政复议**（《行政复议法》第二十三条第二款）？未告知将导致申请期限起算规则对机关不利。

###### 〔审核动作〕4. 答复内容合法性审查

- 答复类型是否准确：依法履行并告知结果／告知不予受理并说明理由／告知转送有权机关／要求补正？
- 不予履行或拒绝履行的，是否**逐项说明具体法律依据与条款**？
- 是否回应了申请人的**全部请求**？有无遗漏或未予答复的事项？
- 答复依据是否现行有效、位阶准确？

##### （二）案卷审核

> 本部分以申请和答复所涉的资料为依据，解决「答复文书本身合法」之外的问题。**审核对象不止答复文本，还包括卷内要件与留痕。**〔审核动作〕逐卷比对下列各项。

###### 1. 卷内要件清单

| 序号 | 要件 | 功能 | 审核要点 |
|---|---|---|---|
| 1 | 履职申请收件登记 | 固定来件要素与**期限起算** | 编号、形式、申请人、登记时间、**两个月届满时间**、申请内容是否齐备 |
| 2 | 受理告知书／联系单 | 告知受理与办理期限 | 是否在收到之日起及时书面告知 |
| 3 | 补正告知书 | 形式要件欠缺时一次性告知补正 | 是否书面告知补正事项与补正期限 |
| 4 | 调查核实材料（科室回复、现场定位、询问笔录、座谈会记录、会议记录） | 证明调查核实过程 | 是否有具体时间、经办人、结论 |
| 5 | 依法履职答复书／行政履职答复书（网答、访答、电答字号） | 导入履职程序的答复 | 规范依据到条、款、项；复议前置告知 |
| 6 | 办理情况报告（台信报字号） | 向区信访办／督查机构报告 | 三段式：申请人基本情况、调查情况及处理意见、程序履行情况 |
| 7 | 律师审核意见 | 内控法律审核 | 送审人、收到日期、文书名称及文号、审核结论、签名日期 |
| 8 | 证据目录／材料目录 | 卷内清单 | 序号、材料名称、页码与实际件数一致 |
| 9 | 送达凭证（送达回证、EMS底单、签收记录） | 固定送达日与救济期限起算 | 受送达人、送达方式、日期、签收签名 |
| 10 | 文书底稿与定稿（「（修改）」前缀稿） | 证明审核与修改过程 | 修改稿与定稿的差异是否已落实 |
| 11 | 上级转办／督办材料 | 说明案件来源与办理方式 | 转办文号、限办日期 |
| 12 | 与申请人沟通留痕（通话录音、微信、照片、视频） | 证明告知与沟通 | 是否归档并注明时间、对象 |

###### 2. 要件完整性审核（勾稽链）

〔审核动作〕按下列链条逐环核对，任一环缺失即在风险意见中标明：

1. **起算环**：收件登记「登记时间／两个月届满时间」→ 受理告知日期 → 答复文书落款日期。**审核时须核验起算口径是否一致**，避免不同文书中同一事项的起算日互相矛盾。
2. **程序环**：受理告知 → （补正告知） → 调查核实 → 履职答复 → 送达。此时须核对**补正期间是否不计入履职期限**及其书面告知。
3. **实体环**：请求事项逐项回应 → 事实与依据对应 → 规范条款到条、款、项。
4. **救济环**：履职答复→**复议前置**＋诉讼告知（60 日复议／6 个月诉讼）。**不得错配为信访复查告知。**
5. **内控环**：送审（送审单／邮件）→ 律师审核意见（载明文书名称及文号）→ 定稿 → 用印 → 送达 → 归档。
6. **证据环**：以「不予立案」「不予受理」结论的，必须有调查核实材料或证据支撑，并**在答复中说明事实与依据**。

###### 3. 常见瑕疵与纠正

〔审核动作〕下列问题均应作为「必改项」逐项标注：

| 瑕疵类型 | 纠正要求 |
|---|---|
| 救济告知缺失或错配 | 履职答复须告知**先行申请行政复议**（60 日）及诉讼（6 个月）；不得告知信访复查 |
| 文号空缺未填 | 发文前填全文号并核对与登记簿一致 |
| 定稿日期未定 | 删除备选、固定落款日期 |
| 文字讹误 | 校核文字，签发前通读 |
| 括号体例不规范 | 公文文号年份应用六角括号〔〕 |
| 引用条文不精确 | 定位到条、款、项 |
| 调查留痕不足 | 附调查核实材料（科室回复、现场定位、询问笔录等），并在审核意见中载明「基于经办人提供事实及调查材料」 |
| 送达留痕不足 | 补送达回证或 EMS 底单、签收记录，固定救济期限起算 |
| 以信访答复代替履职答复 | 导入履职程序的，须出具依法履职答复书，不得以信访处理意见书代替 |
| 未逐项回应请求 | 对申请人的全部请求事项逐项回应，不得遗漏 |

#### 二、风险与建议

> 对每一审核项标注「**明确规定**」（无裁量空间，违反即违法）或「**存在争议**」（规范或裁判尺度不一，须个案权衡），据此形成风险提示与建议。

##### （一）规范属性与审核意见

| 事项 | 属性 | 审核意见 |
|---|---|---|
| 无明确期限时的履职期限（两个月）、履职之诉起诉期限（六个月） | 明确规定 | 法释〔2018〕1号第六十六条；国信发〔2017〕19号第十二条第二款。超期即构成不履行法定职责 |
| 未履行法定职责的复议前置 | 明确规定 | 《行政复议法》第二十三条第一款第三项（2024年1月1日起）；与信息公开「不予公开」复议前置（同条第四项）并行 |
| 不得以诉权免除履职义务 | 明确规定 | 国信发〔2017〕19号第六条第二款 |
| 履职申请与信息公开申请的界分标准 | 存在争议 | 仅有「实质内容」判断原则；应在申请文书中明确请求性质，避免被错误分流 |
| 投诉举报人原告资格（「为维护自身合法权益」） | 存在争议 | 规范依据明确（法释〔2018〕1号第十二条第五项），但「自身合法权益」范围个案裁量空间大 |

##### （二）风险提示与处理建议

- 按高风险／中风险／低风险分级。涉及期限的，须以当前日期 `{today}` 为基准显式计算（例如：当前日期 {today}，两个月届满日 Y，剩余 Z 天／已逾期 Z 天）。
- **申请人视角**：在申请文书中**明确请求性质**（请求作出执法行为，而非索取既存信息），避免被错误分流；留存提交凭证以固定期限起算点；逾期不予答复或拒绝履行的，**须先申请行政复议**（不可径行起诉），复议60 日、起诉自履行期限届满起6 个月。
- **行政机关视角**：补正形式要件与程序瑕疵、完善调查与答复留痕、逐项回应请求；在履职答复文书中**务必书面告知先行申请行政复议**；不得以「享有诉讼权利」为由免除自身履职义务，不得以信访处理意见代替行政处理决定。

#### 三、答复文本审核与标红修改稿

〔审核动作〕完成前述审核后，以本流程所列规范为依据，对**被审文书（依法履职答复书、行政履职答复书、不予受理告知书等）**逐项比对并出具标红修改稿；无被审文书的，直接生成可以直接使用的答复文本。

1. **比对维度**：文书性质定性是否正确 → 引用的依据条款是否现行有效、是否准确（条、款、项） → 程序期限是否在法定期间内 → 答复类型是否适用正确 → 救济途径告知（尤其复议前置告知）是否完备 → 事实与请求是否逐项回应。
2. **标注方式**：**修改／新增处标红**；**删除处用红色删除线**；每处修改**注明修改依据（规范名称＋条款＋来源）**。
3. 核对信息的**名称、文号、制作时间、载体形式**等要素是否具体明确；不明确的，适用补正程序。
4. 核对是否**留存提交凭证**（收件登记、EMS底单等），以便固定受理日与期限起算点。
5. **待填数据**：金额、案号、证号、日期、签章等**客观数据以蓝色标注**，标明「待办案机关回填」，**不得由审核人臆造**。
6. **文本校核**：发文前必查——文号是否填全（含六角括号〔〕）、落款日期是否唯一确定、有无重复字词、「（修改）」稿的意见是否已落实、附件与正文所述材料是否齐备。
7. **输出**：修改稿与「风险与建议」意见表一并提交，并附**审核意见**。

##### 审核意见出具体例

〔审核动作〕审核意见与修改稿同步出具，**不得以修改稿代替审核意见**。体例固定为「**收到日期—送审单位—送审文书名称及文号—审核基础—审核结论—律师签名及日期**」。

> 履职申请事项审核意见
>
> 【收到邮件日期】，法律顾问收到【行政机关】送审的【申请文件名称及文号】。现出具审核意见如下：
>
> 基于经办人提供的事实和调查材料，对申请事项予以区分答复。送审文件律师已审核。
>
> 律师：　　　　　　【日期】

〔审核动作〕出具审核意见时必查：1.送审文书名称与**文号**是否与卷内定稿一致；2.审核基础是否载明（经办人提供的事实、调查材料等）；3.结论是否可执行（区分答复／补正／重新出具）；4.签发日期不得早于送审日期。

##### 修订版文书要求

本类型文书为可修订类型：如发现需要修改之处（请求事项表述、履行依据与理由、履行结果告知、复议前置与救济途径告知等），按上述标注方式输出修改后文书正文（含【新增】【修改】【删除】标记，删除处标红色删除线），每处修改注明修改依据（规范名称＋条款）；金额、案号、证号、日期、签章等客观数据以【待核实】标注，标明「待办案机关回填」，**不得臆造**。若无需修改，revised_document 设为 null。
