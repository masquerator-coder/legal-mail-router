### 投诉、举报类文书专属分析流程

> 本流程适用于**投诉、举报类文书**：申请人反映违法行为要求查处——**投诉**为维护自身权益，**举报**为公益性，规范体系为「通用框架＋领域专门规定＋属地具体渠道」三层。文书性质识别与入口分流已在上游完成，本流程直接进入审核。
> 〔审核顺序〕**审核流程（实体审核 → 案卷审核）→ 风险与建议 → 答复文本审核与标红修改稿**，依次执行，不得跳步。
> 〔体例标注〕〔明确规定〕＝规范明确、几无裁量空间；〔存在争议〕＝规范或裁判尺度不统一，须个案权衡；〔审核动作〕＝本条应执行的核对／留痕动作。
> 文中 `{today}` 为占位符，审核时替换为**审核当日日期**。

#### 一、审核流程

##### （一）实体审核要点

###### 〔审核动作〕1. 投诉、举报的法律定位

- **举报**：任何组织或个人反映违法行为、要求查处——对行政机关产生查处职责，但对举报人原则上不产生个人法益，**举报人原则上无诉权**（公益性举报）。
- **投诉**：为维护自身合法权益反映违法行为（如劳动者投诉用人单位侵害其权益）——行政机关的查处行为与投诉人有利害关系，投诉人可依法释〔2018〕1号第十二条第五项提起履职之诉，并依《行政复议法》第二十三条第一款第三项**先行申请行政复议**。
- 一份材料同时具备投诉与举报性质时，须按**主张对象与权益归属**分别定性，并分别适用对应的原告资格与救济规则。

###### 〔审核动作〕2. 中央工作指令：信访工作法治化

中共中央办公厅、国务院办公厅《关于着力推进信访工作法治化的意见》围绕预防、受理、办理、监督追责、维护秩序「**五个法治化**」制定「路线图」和「导引图」，配套国家信访局《信访事项通用办理指南》。核心指令：

- **受理环节**：来访（信）必登、准确转送交办、规范告知，严格执行「**三个不予受理**」和「**两个不再受理**」；
- **办理环节**：深入推进分类处理，不得以信访答复代替依法履职、不得以过程性工作代替处理意见、不得以程序性办结代替实体性化解；
- **监督环节**：对应受理而不受理、应办理而不办理、超期不答复的督办问责；信访部门履行「三项建议」（改进工作、完善政策、追究责任）职责。

###### 〔审核动作〕3. 分类导入规则

投诉举报事项属于申请查处违法行为、履行保护人身权或财产权职责的，依法履行或答复（无具体期限规定的**两个月内**）；属于其他行政程序（行政处罚、行政许可、行政裁决等）的导入相应程序；**不得以信访处理代替行政处理**（国信发〔2017〕19号第六条、第十五条；《信访工作条例》第三十一条第一款第五项）。

###### 〔审核动作〕5. 分领域处理规则明细

**（一）人社领域（劳动保障监察）**

- 受理范围：用人单位违反劳动保障法律法规的行为；拖欠工资适用《保障农民工工资支付条例》（国务院令第724号）。
- **查处时效**：违反劳动保障法律的行为在**2 年内**未被有关部门发现、也未被举报投诉的，不再查处（《劳动保障监察条例》第二十条）。〔明确规定〕
- **调查期限**：自立案之日起**60 个工作日**内完成；情况复杂经批准可延长**30 个工作日**（条例第十七条）。〔明确规定〕
- **立案审查期限、书面告知**等程序细节适用《关于实施〈劳动保障监察条例〉若干规定》（劳动和社会保障部令第25号）。
- 劳动者投诉属「为维护自身合法权益」的投诉，对不履行查处职责可复议前置后提起履职之诉。

**（二）应急管理领域（安全生产举报）**

- 《安全生产法》（2021年修正）第七十四条：任何单位或个人对事故隐患或安全生产违法行为均有权报告或举报；监管部门应当建立举报受理制度，公开举报电话、信箱或电子邮件地址；对举报经调查属实的，给予奖励。
- 《安全生产领域举报奖励办法》（应急〔2018〕19号）：奖励以举报事实清楚、对象明确为条件，按行政处罚罚款金额一定比例计算并设上下限。
- 天津市执行口径：12350热线24 小时受理，受理核查**10 个工作日内回复结果**；实名举报核查属实按处罚金额最低奖励3000 元、最高30 万元，举报人信息严格保密。
- 举报人原则上无诉权（公益性质）；但举报同时请求保护自身人身财产权益的，按投诉处理并具有利害关系（法释〔2018〕1号第十二条第五项）。〔边界个案有分歧〕

**（三）住建领域（工程质量、招投标、物业）**

- **工程质量**：建设单位、勘察设计施工监理单位违反《建设工程质量管理条例》（国务院令第279号）的，任何人有权向住建部门检举、控告；天津市执行《天津市建设工程质量管理条例》。
- **招投标投诉**：投标人或其他利害关系人认为招标投标活动不符合法律、行政法规规定的，可以自知道或者应当知道之日起**10 日内**向有关行政监督部门投诉；行政监督部门收到投诉后**3 个工作日内**决定是否受理，并自受理之日起**30 个工作日内**作出书面处理决定（《招标投标法实施条例》第六十条、第六十一条）。〔明确规定〕
- **物业管理**：街道办组织召集物业管理联席会议、协调解决（《天津市街道办事处条例》第二十八条）。

**（四）征地与土地整理领域**

- 区土地整理中心系征地项目的**建设单位（实施主体）**，征收土地申请、公告及补偿安置决定的法定职责在县级以上地方人民政府；对征地程序或补偿的异议**不应向土地整理中心主张履职**，其不是适格的查处对象。
- **补偿安置方案异议**：多数被征地权利人对方案有异议的，政府应组织听证（《土地管理法实施条例》第二十八条）；批前补偿安置方案属阶段性程序行为，司法实践一般认为不可单独复议、诉讼。〔存在争议〕
- 对未达成协议的，政府应作出**征地补偿安置决定**（实施条例第三十一条）；对该决定不服可依法申请行政复议或提起行政诉讼；拒不交出土地的由政府责令交地并申请法院强制执行（实施条例第六十二条）。
- **违法用地、违法征地举报**：12336自然资源违法举报渠道或12345转办，由规划资源部门（天津市规划和自然资源局津南分局）查处；举报人无诉权，被征地农民就自身权益按上述救济路径主张。

##### （二）案卷审核

> 本部分以申请和答复所涉的资料为依据，解决「答复文书本身合法」之外的问题。**审核对象不止答复文本，还包括卷内要件与留痕。**〔审核动作〕逐卷比对下列各项。

###### 2. 要件完整性审核（勾稽链）

〔审核动作〕按下列链条逐环核对，任一环缺失即在风险意见中标明：

1. **起算环**：收件登记「登记时间／限办时间」→ 受理告知日期 → 答复文书落款日期。**审核时须核验起算口径是否一致**，避免不同文书中同一事项的起算日互相矛盾。
2. **程序环**：受理告知 → 调查核实 → 处理结果回复 → 送达。此时须核对**调查期限是否在法定期间内**（如劳动监察60＋30 个工作日）。
3. **实体环**：投诉举报事项逐项回应 → 事实与依据对应 → 规范条款到条、款、项。
4. **救济环**：投诉（为维护自身合法权益）→**复议前置**＋诉讼告知；举报（公益性）→告知核查处理结果，不服按法定途径。**不得错配。**
5. **内控环**：送审（送审单／邮件）→ 律师审核意见（载明文书名称及文号）→ 定稿 → 用印 → 送达 → 归档。
6. **证据环**：以「不予立案」「不予受理」结论的，必须有调查核实材料或证据支撑，并**在答复中说明事实与依据**。

###### 3. 常见瑕疵与纠正

〔审核动作〕下列问题均应作为「必改项」逐项标注：

| 瑕疵类型 | 纠正要求 |
|---|---|
| 救济告知缺失或错配 | 投诉（为维护自身合法权益）须告知**先行申请行政复议**（60 日）及诉讼（6 个月）；举报（公益性）告知核查处理结果 |
| 文号空缺未填 | 发文前填全文号并核对与登记簿一致 |
| 定稿日期未定 | 删除备选、固定落款日期 |
| 文字讹误 | 校核文字，签发前通读 |
| 括号体例不规范 | 公文文号年份应用六角括号〔〕 |
| 引用条文不精确 | 定位到条、款、项 |
| 调查留痕不足 | 附调查核实材料（科室回复、现场定位、询问笔录等），并在审核意见中载明「基于经办人提供事实及调查材料」 |
| 送达留痕不足 | 补送达回证或 EMS 底单、签收记录，固定救济期限起算 |
| 泄露举报人信息 | 严格保密举报人信息；不得将检举揭发材料转给被检举人（《信访工作条例》第三十条第三款） |
| 以信访答复代替依法履职 | 投诉举报属履职请求的，须出具依法履职答复书，不得以信访处理意见书代替 |
| 举报奖励未依法兑现 | 属实举报的，依法告知与兑现奖励（奖励条件、标准与发放渠道） |

##### （二）风险提示与处理建议

- 按高风险／中风险／低风险分级。涉及期限的，须以当前日期 `{today}` 为基准显式计算（例如：当前日期 {today}，受理／处理届满日 Y，剩余 Z 天／已逾期 Z 天）。
- **投诉举报人视角**：以**书面形式**（EMS邮寄并留存底单，或通过12345平台提交）向有查处职责的机关提出，载明请求、事实、理由；同时通过**12345登记**获取工单编号，利用其刚性办结时限形成程序约束；要求行政机关**书面告知受理及处理结果**。属「为维护自身合法权益」的投诉，对不履行查处职责可**复议前置**后提起履职之诉；纯公益性举报原则上无诉权，宜通过12345与监督渠道推动。
- **机关视角**：补正受理与告知程序、完善调查与答复留痕、逐项回应；**不得泄露举报人信息**；不得以信访答复代替依法履职；属实举报依法兑现奖励。

#### 三、答复文本审核与标红修改稿

〔审核动作〕完成前述审核后，以本流程所列规范为依据，对**被审文书（举报受理告知书、核查处理结果回复、依法履职答复书等）**逐项比对并出具标红修改稿；无被审文书的，直接生成可以直接使用的答复文本。

1. **比对维度**：文书性质定性是否正确 → 引用的依据条款是否现行有效、是否准确（条、款、项） → 程序期限是否在法定期间内 → 答复类型是否适用正确 → 救济途径告知（尤其复议前置告知）是否完备 → 事实与请求是否逐项回应。
2. **标注方式**：**修改／新增处标红**；**删除处用红色删除线**；每处修改**注明修改依据（规范名称＋条款＋来源）**。
3. 核对信息的**名称、文号、制作时间、载体形式**等要素是否具体明确；不明确的，适用补正程序。
4. 核对是否**留存提交凭证**（收件登记、EMS底单、12345工单编号等），以便固定受理日与期限起算点。
5. **待填数据**：金额、案号、证号、日期、签章等**客观数据以蓝色标注**，标明「待办案机关回填」，**不得由审核人臆造**。
6. **文本校核**：发文前必查——文号是否填全（含六角括号〔〕）、落款日期是否唯一确定、有无重复字词、「（修改）」稿的意见是否已落实、附件与正文所述材料是否齐备。
7. **输出**：修改稿与「风险与建议」意见表一并提交，并附**审核意见**。

##### 审核意见出具体例

〔审核动作〕审核意见与修改稿同步出具，**不得以修改稿代替审核意见**。体例固定为「**收到日期—送审单位—送审文书名称及文号—审核基础—审核结论—律师签名及日期**」。

> 投诉举报事项审核意见
>
> 【收到邮件日期】，法律顾问收到【行政机关】送审的【申请文件名称及文号】。现出具审核意见如下：
>
> 基于经办人提供的事实和调查材料，对投诉举报事项予以区分答复。送审文件律师已审核。
>
> 律师：　　　　　　【日期】

〔审核动作〕出具审核意见时必查：1.送审文书名称与**文号**是否与卷内定稿一致；2.审核基础是否载明（经办人提供的事实、调查材料等）；3.结论是否可执行（区分答复／补正／重新出具）；4.签发日期不得早于送审日期。

##### 修订版文书要求

本类型文书为可修订类型：如发现需要修改之处（请求事项表述、受理与处理依据、逐项回应、救济途径告知等），按上述标注方式输出修改后文书正文（含【新增】【修改】【删除】标记，删除处标红色删除线），每处修改注明修改依据（规范名称＋条款）；金额、案号、证号、日期、签章等客观数据以【待核实】标注，标明「待办案机关回填」，**不得臆造**。若无需修改，revised_document 设为 null。
