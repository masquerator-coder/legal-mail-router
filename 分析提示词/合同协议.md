### 合意类文书(合同/协议)专属分析流程

我方代表甲方立场。按以下顺序审查:条款完整性 → 有效性 → 利益平衡 → 表述准确性 → 风险防范。

#### 1. 条款完整性审查

对照《民法典》第四百七十条及常见交易惯例,检查合同是否缺少以下必备或重要条款:

- 当事人信息(名称、地址、联系方式)
- 标的物/服务内容及规格
- 数量/质量标准
- 价款及支付方式(含发票、税费承担)
- 履行期限、地点和方式
- 违约责任
- 争议解决方式(诉讼/仲裁,管辖机构)
- 合同解除条件
- 保密义务
- 知识产权归属(若涉创造性成果)
- 通知与送达地址
- 不可抗力
- 合同生效条件及签署条款

若缺失,须在报告中逐项列出,并说明缺失项可能带来的风险。

#### 2. 逐条高风险条款审查

| 条款类别 | 审查要点 |
| :--- | :--- |
| 违约责任 | 违约金比例是否畸高(日息超万分之五或总额超合同总价30%)、是否仅单方约定、是否未设责任上限、是否包含"一切损失""预期利益"等无限赔偿表述 |
| 免责与不可抗力 | 是否排除不可抗力免责、不可抗力定义是否过窄、是否未约定通知及减损义务 |
| 自动续约 | 通知窗口期是否过短(<30天)、续约期限是否过长(≥原期)、是否默示续约而未要求书面确认 |
| 知识产权 | 是否混淆背景IP与新增成果、是否要求永久免费授权、是否未约定侵权责任承担 |
| 争议解决 | 管辖法院/仲裁机构是否对客户不利(如对方所在地)、是否同时约定仲裁和诉讼(无效)、是否排除法院管辖而强制仲裁 |
| 单方变更权 | 是否允许一方单方调整价格、服务范围、付款条件等,而无须对方同意 |
| 付款与验收 | 付款节点是否与验收挂钩且验收条件严苛、是否未设合理异议期、"视为验收合格"条款是否公允 |
| 担保条款 | 自然人担保是否取得公司决议、保证方式是否为一般保证(而非连带) |
| 解除权 | 是否仅赋予一方任意解除权、解除后果是否清晰(返还、赔偿) |

#### 3. 引用原文的强制性规范

- 逐字摘录:对每一条被认定为风险的条款,必须原文抄录,不得概括、缩写或改写。若条款较长(超过100字),可摘录包含"金额、期限、百分比、权利义务"的核心句,但须用 `[……]` 标明省略位置,且不得改变原意。
- 定位标注:每条引用须同时注明条款序号和所在页码(格式:【第X条第X款,第X页】)。
- 存疑处理:若扫描件文字模糊或存在歧义,须在引用后标注【⚠️ 原文辨识存疑,请律师核对原件】,并据此进行分析,切勿过度解读。

#### 4. 风险分级与判断标准

- 🔴 高风险:条款违反法律强制性规定、可能导致客户承担远超正常商业风险的损失,或基本权利被剥夺(如无限连带责任、无上限违约金、单方任意解约权)。
- 🟡 中风险:条款偏离市场惯例、存在潜在纠纷隐患,但通过谈判有望修正(如管辖地不公、通知期过短)。
- 🟢 低风险:条款表述不够明确,但影响有限,或客户方有较强谈判地位可接受。

#### 5. 修改建议的生成要求

- 每条建议须包含修改理由(可引用法律条文,如《民法典》第585条关于违约金调整的规定)和具体修改措辞(直接给出可替换的文本)。
- 若涉及商业条款(如价格、数量),应提示客户与业务部门确认,律师仅从法律角度提供风险边界。

#### 6. 缺失重要条款补遗

若发现合同遗漏重大条款(如违约责任上限、争议解决、不可抗力等),须在分析报告中明确提出"建议增加以下条款",并草拟具体条款文本(供客户参考)。

#### 7. 审查结果整理与自检

将以上分析结论整理为:问题清单(按风险等级排序)、逐条原文引用及修改建议、建议新增或删除的条款内容、整体风险评估及谈判策略方向。输出前执行自检:

- 每处原文引用是否与合同文字完全一致(数字、日期、但书)?
- 是否遗漏条款的例外情形或前提条件?
- 跨条款关联是否已核对被引条款的实际内容?
- 所有引用是否均包含"条款序号+页码"定位?

#### 8. 修订版文书要求

本类型文书**必须生成** revised_document:按主模板「生成修改版文书」章节的修订规则与改动标记规范,输出完整的修改后合同正文(含【新增】【修改】【删除】标记)。若修订建议与现行法律法规强制性规定明显冲突,原文保留并标注【待核实】。
