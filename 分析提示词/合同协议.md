### 合意类文书(合同/协议)专属分析流程

我方(即客户)默认按甲方立场分析;若合同内容显示我方为乙方,则改为乙方立场,并在报告开头注明所采用的立场。随后按以下顺序审查:合同分类 → 六维审查(合法性·完整性·可操作性·逻辑连贯性·表述规范性·无歧义) → 重点高风险条款 → 特定类型专项 → 风险分级 → 修改建议 → 修订版文书。

> 本流程适用于一般民商事合同的常规审查;特定交易类型(建设工程、涉外、金融、涉国资等)在六维审查基础上叠加专门要点(见第3节)。标注【明确规定】者现行法有明确规则,标注【存在争议】或【个案判断】者实践有分歧或需结合个案事实认定。审查应结合交易背景与客户交易目的,对高风险条款出具书面修改意见。

#### 0. 合同分类与审查路径

- **识别交易类型**:先判定合同性质(买卖、租赁、承揽、服务、借款、合作、建设工程、知识产权许可、股权投资、涉外等),据此确定审查路径——一般民商事合同适用第1—2节;特定类型叠加第3节专项要点。
- **判定我方立场**:确认我方为甲方或乙方,全程站在客户立场识别对其不利的条款;立场存疑时在报告开头注明所采用的立场。
- **名实核对**:合同名称与实际权利义务关系不符的,按实际法律关系认定并适用对应规则(法释〔2023〕13号第15条)。

#### 1. 六维审查要点

##### (一)合法性审查

- **主体资格与签约权限**:当事人依法设立、有效存续,名称与统一社会信用代码同登记信息一致(以国家企业信用信息公示系统为准);由法定代表人或持授权委托书的代理人签署,核对印章真实性与预留印鉴;越权代表未经追认、相对人又未尽合理审查义务的对公司不发生效力(民法典第504条、法释〔2023〕13号第20、21条)。【明确规定,个案认定】
- **内容合法与公序良俗**:不违反法律、行政法规的效力性强制性规定(第153条第1款),不危害国家安全、损害社会公共秩序、违背善良风俗(第153条第2款),无恶意串通损害他人合法权益(第154条);超越经营范围订立不当然无效,但违反国家限制经营、特许经营及禁止经营规定的除外(第505条)。【明确规定】
- **资质与特别程序**:建筑、金融、医药、危化品等特许行业须具备相应资质或许可(无资质或借用资质签订建设工程施工合同无效,法释〔2020〕25号第1条);涉招标投标、国有资产转让、上市公司重大交易的,核实法定程序是否履行(招标投标法第46条、企业国有资产法)。【明确规定】
- **审批生效**:法律、行政法规规定应办理批准等手续的,未经批准合同未生效,报批义务条款独立有效(第502条第2款、法释〔2023〕13号第12条)。【明确规定】
- **无效免责条款**:排除造成对方人身损害责任、因故意或重大过失造成对方财产损失责任的免责条款无效(第506条)。【明确规定】
- **格式条款**:提供方就免除或减轻其责任等与对方有重大利害关系的条款负提示、说明义务,未履行的对方可主张不成为合同内容(第496条);不合理免除或减轻己方责任、加重对方责任、限制或排除对方主要权利的无效(第497条);争议按通常理解并作不利于提供方的解释(第498条)。【明确规定】
- **"背靠背"条款**:大型企业与中小企业约定以收到第三方款项为付款前提的条款无效,付款期限由法院结合行业规范、交易习惯合理确定(法释〔2024〕11号)。【明确规定】

##### (二)完整性审查(条款完整性)

- 对照民法典第470条核查**条款完整性**:当事人信息(名称/住所/统一社会信用代码/联系人及送达地址)、标的(名称/规格/型号/数量/质量标准,可特定化)、价款(金额大小写/币种/是否含税/发票类型/支付方式与期限)、履行(期限/地点/方式/验收标准与异议期)、违约责任、争议解决、生效条款、解除条款。第470条为**倡导性规定**,缺失**不导致合同无效**,可依第510、511条补充解释,但增加履约争议风险——须逐项列明缺失项及其风险。当事人名称、标的、数量为合同成立的最低要素(法释〔2023〕13号第3条)。
- **特别条款按交易性质配置**:保密、知识产权归属、竞业限制、履约保证金、所有权保留(第641条)、数据与个人信息保护(个人信息保护法第13条)、反商业贿赂等。
- **附件体系**:附件清单完整,附件与正文效力关系明确,技术规格书、报价单等文件版本锁定,避免履行中被替换或产生"以何者为准"争议。

##### (三)可操作性审查

- **履行要素"五明确"**:每项义务明确履行主体、内容、期限、地点、方式;约定不明按第510、511条法定填补,结果可能偏离商业意图、对己方未必有利。
- **付款条件客观可验证**:付款前提应为客观可验证事件(如财政资金拨付到位且收款方提供发票),主观条件成就与否不明,诉讼中举证与认定困难;同时核实是否落入法释〔2024〕11号"背靠背"无效情形。【存在争议,个案判断】
- **通知与送达**:约定送达地址、方式、地址变更通知义务及"视为送达"规则;未约定的依民事诉讼法送达,周期长、成本高。
- **程序闭环**:验收、对账、结算、异议提出与处理均设定期限和流程(买受人检验通知义务第620、621条,未在合理期限内通知视为符合约定)。【明确规定】
- **违约金可计算**:明确计算基数、比例或金额、累计上限及其与损失赔偿的关系(第585条,约定过高可请求适当减少)。【调整标准属司法裁量】
- **救济措施可用**:继续履行、补救措施、赔偿损失、定金、担保等与违约情形对应配置(第577—588条;守约方减损义务第591条)。
- **争议解决单一、确定**:选择诉讼的约定明确且唯一的管辖法院;选择仲裁的明确仲裁事项与选定的仲裁机构,机构约定不明且达不成补充协议的仲裁协议无效(仲裁法2025年修订第27、29条,原第16、18条);**禁用"或裁或诉"**(仲裁法司法解释第7条,既约定仲裁又约定诉讼的原则上仲裁协议无效)。【明确规定】

##### (四)逻辑连贯性审查

- **术语一致**:同一概念全文使用统一称谓,定义条款界定的术语与正文逐一对应(如"货款"与"合同款"混用是争议高发点)。
- **权责对等**:各方权利义务、风险与费用负担的配置与合同性质、交易流程匹配(公平原则第6条);显著失衡可能触发格式条款无效或显失公平撤销(第151条)。
- **条款衔接**:违约责任所指向的义务条款真实存在;付款节点与验收、交付节点对应,避免违约条款引用不存在的义务导致责任落空。
- **数量勾稽**:单价×数量=总价;分期付款合计=合同总价;大小写金额一致(矛盾时按法释〔2023〕13号第1条解释:词句通常含义＋相关条款＋合同性质和目的＋习惯＋诚信原则)。
- **交叉引用准确**:"详见第X条""见附件X"所指条款、附件真实且内容对应。
- **文件效力层级**:主合同、补充协议、附件、招标投标文件、往来函件之间的效力顺序及冲突规则明确(法释〔2023〕13号第14条多份合同的认定、第15条名实不符按实际法律关系认定)。【明确规定】
- **时间逻辑**:合同生效日早于履行期起算日;异议期、保证期间、质保期、诉讼时效(第188条)起算点先后有序、无重叠冲突。
- **版本唯一**:确认无"阴阳合同",谈判过程中的不同版本已被替代或作废(以虚假意思表示订立的合同无效,第146条)。【明确规定】

##### (五)表述规范性审查

- **术语规范**:使用规范法律术语和行业标准表述,关键术语在定义条款中集中界定;自创术语或行业俗称未定义的解释成本高。
- **期限表述规范**:区分"工作日"与"自然日""日历天",明确期限起算点(第200—204条期间计算规则)。【明确规定】
- **数额表述规范**:金额大小写一致并注明币种;"以上""以下""以内""届满"包括本数,"不满""超过""以外"不包括本数(第1259条)。【明确规定】
- **标点与文字**:全角标点规范使用,无错别字、漏字、多字,条款编号连续无跳号(形式审查必查项)。
- **简称与外文**:简称、外文缩写首次出现时注明全称;中外文文本效力及解释顺序有约定,避免歧义时无据可依。
- **模板清理**:对方名称、项目信息、地址、日期、金额等替换完整;选择性条款("□是□否")已作勾选或删除(模板残留他方信息是高频低级错误)。

##### (六)无歧义审查

- **消除模糊词**:"及时""合理""适当""相关"等弹性表述尽量量化或设定判断基准;无法量化的依赖第510、511条补充,存在不确定性。
- **指代唯一**:明确使用"甲方/乙方""双方/各方",避免"该公司""对方""其"等指代不明(多方合同中尤为高发)。
- **句式清晰**:拆分长句,避免多重否定,并列项使用列举式而非顿号堆叠(歧义句式按法释〔2023〕13号第1条解释;格式条款歧义适用不利解释第498条)。【明确规定】
- **义务主体与程度明确**:逐项核对"应当"(义务)、"有权"(权利)、"可以"(选择权)的使用,每项义务有明确责任方;混用将改变条款性质。
- **"包括但不限于"边界清晰**:列举项与兜底项外延匹配,避免被解释为无限扩张。【个案判断】
- **或有条款触发条件明确**:生效条件、解除条件、价格调整机制等载明客观触发事件和后果(附条件民事法律行为第158—160条)。【明确规定】
- **避免自相矛盾**:同一事项在不同条款中的要求一致(如保密期限、质保范围、验收标准);矛盾条款以体系解释、目的优先,存在裁量空间。【个案判断】

#### 2. 重点高风险条款专项审查

| 条款类别 | 审查要点 |
| :--- | :--- |
| 违约责任 | 是否**过分高于违约造成的损失**(依《合同编通则解释》第65条,**以实际损失为基础**,一般认为**约定违约金超过造成损失的30%**可初步认定为过高);注意30%是"是否启动调整"的**触发线而非调整目标**,不得机械按损失的130%给出建议;是否属**恶意违约**(恶意违约的当事人请求减少违约金,法院一般不予支持);是否仅单方约定、是否未设责任上限、是否包含"一切损失""预期利益"等无限赔偿表述(赔偿范围受《民法典》第584条**可预见性规则**限制);是否约定**定金**(定金不得超过主合同标的额20%,且违约金与定金**择一适用**) |
| 免责与不可抗力 | 是否排除不可抗力免责、不可抗力定义是否过窄、是否未约定通知及减损义务(依《民法典》第590条应及时通知并在合理期限内提供证明;迟延履行后发生不可抗力的不免责;第591条对方负有防止损失扩大的义务);是否存在**依法无效**的免责条款(第506条:造成对方**人身损害**的、因**故意或者重大过失**造成对方财产损失的免责条款**无效**) |
| 格式条款 | 是否为一方**预先拟定、重复使用、未与对方协商**的格式条款;提供方是否就**免除或者减轻其责任等与对方有重大利害关系**的条款履行**提示和说明义务**(未履行的,对方可主张该条款**不成为合同的内容**,第496条);是否存在**不合理地免除或减轻自己责任、加重对方责任、限制对方主要权利**,或**排除对方主要权利**的情形(**无效**,第497条);争议解释是否按通常理解并作出**不利于提供格式条款一方**的解释(第498条) |
| 自动续约 | 通知窗口期是否过短(<30天)、续约期限是否过长(≥原期)、是否默示续约而未要求书面确认 |
| 知识产权 | 是否混淆背景IP与新增成果、是否要求永久免费授权、是否未约定侵权责任承担 |
| 争议解决 | 管辖法院/仲裁机构是否对客户不利(如对方所在地);是否**同时约定仲裁和诉讼**(约定争议可以申请仲裁也可以起诉的,**仲裁协议无效**,《仲裁法司法解释》第7条);是否排除法院管辖而强制仲裁;仲裁条款是否明确约定**仲裁事项与选定的仲裁机构**(约定不明且未能补充协议的,仲裁协议无效) |
| 单方变更权 | 是否允许一方单方调整价格、服务范围、付款条件等,而无须对方同意 |
| 付款与验收 | 付款节点是否与验收挂钩且验收条件严苛、是否未设合理异议期、"视为验收合格"条款是否公允 |
| 担保条款 | **公司对外担保**:是否经**董事会或者股东会决议**(《公司法》2023年修订第15条);为公司**股东或实际控制人**提供担保的,是否经**股东会决议**;相对人是否对决议尽到**合理审查**(《担保制度司法解释》第7条:相对人非善意的,担保合同对公司**不发生效力**)。**保证方式**:未约定或约定不明的,依《民法典》第686条第2款**按一般保证承担保证责任**(此为对旧《担保法》"推定连带"的**翻转**),保证人享有**先诉抗辩权**(第687条);若为连带责任保证,须有明确约定 |
| 解除权 | 是否仅赋予一方任意解除权、解除后果是否清晰(返还、赔偿) |

#### 3. 特定类型合同专项要点(按第0节分类触发)

> 一般民商事合同仅适用第1—2节;下列特定类型在六维审查基础上叠加专项要点。其他未列类型(涉外、金融、涉国资、知识产权许可、股权投资等)应结合监管要求与交易结构另行补充专门维度。

**建设工程合同专项**("建工解释一"指《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释(一)》法释〔2020〕25号;勘察、设计、EPC合同参照适用):

| 要点 | 审查内容 |
| :--- | :--- |
| 资质与招投标 | 承包人资质等级与工程规模匹配,无资质、超越资质、借用资质(挂靠)签约无效(民法典第791条、建筑法第26条、建工解释一第1条;超越资质但竣工前取得相应资质的不作无效处理,第4条);依法必须招标的项目未招标或中标无效的合同无效(招标投标法第3条、《必须招标的工程项目规定》发改委令第16号)【明确规定】 |
| 黑白合同 | 另行签订的合同背离中标合同实质性内容(工程范围、工期、质量、价款)的,以中标合同确定权利义务;变相让利(高价回购承建房产、无偿配套、捐赠等)有被认定无效风险(建工解释一第2条);与招投标文件不一致的可按招投标文件结算(第22、23条)【明确规定】 |
| 规划手续 | 发包人未取得建设工程规划许可证等规划审批手续的施工合同无效(起诉前补办的除外,建工解释一第3条)【明确规定】 |
| 转包与违法分包 | 禁止转包、肢解发包、违法分包,主体结构施工须由总承包人自行完成,再分包禁止(民法典第791条、建筑法第28、29条、建工解释一第1条第2款;违法情形认定见建市规〔2019〕1号;劳务分包不因此无效,第5条)【明确规定】 |
| 无效结算后果 | 合同无效但工程质量合格的,可参照合同关于工程价款的约定折价补偿(民法典第793条、建工解释一第24条:数份合同均无效的参照实际履行的合同,难以确定的参照最后签订的合同)【明确规定】 |
| 实际施工人 | 转包、违法分包情形下实际施工人可直接起诉发包人,发包人在欠付工程款范围内担责(建工解释一第43条突破合同相对性、第44条代位权诉讼)——发包人应核实实际施工人身份、锁定付款路径与凭证【明确规定】 |
| 农民工工资 | 核实农民工工资专用账户、实名制管理、总包代发及先行清偿责任的合同安排(《保障农民工工资支付条例》国务院令第724号)【明确规定】 |
| 计价与调差 | 明确计价方式(固定总价/固定单价/可调价)及人工、材料价格波动的调差机制与风险幅度;固定价结算的法院不支持造价鉴定申请(建工解释一第19条计价约定优先、设计变更部分协商不成的参照签约时当地建设主管部门计价方法或标准,第28条)【明确规定】 |

#### 5. 风险分级与判断标准

- 🔴 高风险:条款违反法律强制性规定、可能导致客户承担远超正常商业风险的损失,或基本权利被剥夺(如无限连带责任、无上限违约金、单方任意解约权)。

- 🟢 低风险:条款表述不够明确,但影响有限,或客户方有较强谈判地位可接受。
