### 合意类文书(合同/协议)专属分析流程

我方(即客户)默认按甲方立场分析;若合同内容显示我方为乙方,则改为乙方立场,并在报告开头注明所采用的立场。随后按以下顺序审查:条款完整性 → 有效性 → 利益平衡 → 表述准确性 → 风险防范。

#### 1. 条款完整性审查

对照《民法典》第四百七十条及常见交易惯例,检查合同是否缺少以下**常备或重要条款**(注意:第四百七十条为"合同的内容由当事人约定,**一般包括**下列条款"的**倡导性/提示性规定,并非强制性规定**,缺失条款**不导致合同无效**,可依《民法典》第510条、第511条补充解释规则处理,但会增加履约争议风险):

- 当事人信息(名称、地址、联系方式)
- 标的物/服务内容及规格
- 数量/质量标准
- 价款及支付方式(含发票、税费承担)
- 履行期限、地点和方式
- 违约责任
- 争议解决方式(诉讼/仲裁,管辖机构)
- 合同解除条件
- 保密义务
- 知识产权归属(若涉创造性成果)
- 通知与送达地址
- 不可抗力
- 合同生效条件及签署条款

若缺失,须在报告中逐项列出,并说明缺失项可能带来的风险。

#### 2. 逐条高风险条款审查

| 条款类别 | 审查要点 |
| :--- | :--- |
| 违约责任 | 是否**过分高于违约造成的损失**(依《合同编通则解释》第65条,**以实际损失为基础**,一般认为**约定违约金超过造成损失的30%**可初步认定为过高);注意30%是"是否启动调整"的**触发线而非调整目标**,不得机械按损失的130%给出建议;是否属**恶意违约**(恶意违约的当事人请求减少违约金,法院一般不予支持);是否仅单方约定、是否未设责任上限、是否包含"一切损失""预期利益"等无限赔偿表述(赔偿范围受《民法典》第584条**可预见性规则**限制);是否约定**定金**(定金不得超过主合同标的额20%,且违约金与定金**择一适用**) |
| 免责与不可抗力 | 是否排除不可抗力免责、不可抗力定义是否过窄、是否未约定通知及减损义务(依《民法典》第590条应及时通知并在合理期限内提供证明;迟延履行后发生不可抗力的不免责;第591条对方负有防止损失扩大的义务);是否存在**依法无效**的免责条款(《民法典》第506条:造成对方**人身损害**的、因**故意或者重大过失**造成对方财产损失的免责条款**无效**) |
| 格式条款 | 是否为一方**预先拟定、重复使用、未与对方协商**的格式条款;提供方是否就**免除或者减轻其责任等与对方有重大利害关系**的条款履行**提示和说明义务**(未履行的,对方可主张该条款**不成为合同的内容**,第496条);是否存在**不合理地免除或减轻自己责任、加重对方责任、限制对方主要权利**,或**排除对方主要权利**的情形(**无效**,第497条);争议解释是否按通常理解并作出**不利于提供格式条款一方**的解释(第498条) |
| 自动续约 | 通知窗口期是否过短(<30天)、续约期限是否过长(≥原期)、是否默示续约而未要求书面确认 |
| 知识产权 | 是否混淆背景IP与新增成果、是否要求永久免费授权、是否未约定侵权责任承担 |
| 争议解决 | 管辖法院/仲裁机构是否对客户不利(如对方所在地);是否**同时约定仲裁和诉讼**(约定争议可以申请仲裁也可以起诉的,**仲裁协议无效**,《仲裁法司法解释》第7条);是否排除法院管辖而强制仲裁;仲裁条款是否明确约定**仲裁事项与选定的仲裁机构**(约定不明且未能补充协议的,仲裁协议无效) |
| 单方变更权 | 是否允许一方单方调整价格、服务范围、付款条件等,而无须对方同意 |
| 付款与验收 | 付款节点是否与验收挂钩且验收条件严苛、是否未设合理异议期、"视为验收合格"条款是否公允 |
| 担保条款 | **公司对外担保**:是否经**董事会或者股东会决议**(《公司法》2023年修订第15条);为公司**股东或实际控制人**提供担保的,是否经**股东会决议**;相对人是否对决议尽到**合理审查**(《担保制度司法解释》第7条:相对人非善意的,担保合同对公司**不发生效力**)。**保证方式**:未约定或约定不明的,依《民法典》第686条第2款**按一般保证承担保证责任**(此为对旧《担保法》"推定连带"的**翻转**),保证人享有**先诉抗辩权**(第687条);若为连带责任保证,须有明确约定 |
| 解除权 | 是否仅赋予一方任意解除权、解除后果是否清晰(返还、赔偿) |

#### 3. 引用原文的强制性规范

- 逐字摘录:对每一条被认定为风险的条款,必须原文抄录,不得概括、缩写或改写。若条款较长(超过100字),可摘录包含"金额、期限、百分比、权利义务"的核心句,但须用 `[……]` 标明省略位置,且不得改变原意。
- 定位标注:每条引用须同时注明条款序号和所在页码(格式:【第X条第X款,第X页】)。
- 存疑处理:若扫描件文字模糊或存在歧义,须在引用后标注【⚠️ 原文辨识存疑,请律师核对原件】,并据此进行分析,切勿过度解读。

#### 4. 风险分级与判断标准

- 🔴 高风险:条款违反法律强制性规定、可能导致客户承担远超正常商业风险的损失,或基本权利被剥夺(如无限连带责任、无上限违约金、单方任意解约权)。
- 🟡 中风险:条款偏离市场惯例、存在潜在纠纷隐患,但通过谈判有望修正(如管辖地不公、通知期过短)。
- 🟢 低风险:条款表述不够明确,但影响有限,或客户方有较强谈判地位可接受。

#### 5. 修改建议的生成要求

- 每条建议须包含修改理由(可引用法律条文,如《民法典》第585条关于违约金调整的规定、《合同编通则解释》第65条关于"过分高于造成的损失"的判断标准)和具体修改措辞(直接给出可替换的文本)。
- 引用法条时须注意**法律版本与施行时间**:涉及公司对外担保应引《公司法》(2023年修订,2024年7月1日施行)第15条;涉及仲裁条款应注明《仲裁法》已于2025年9月12日修订、**2026年3月1日施行**,条号已重排,应按法律事实发生时间选择适用版本。
- 若涉及商业条款(如价格、数量),应提示客户与业务部门确认,律师仅从法律角度提供风险边界。

#### 6. 缺失重要条款补遗

若发现合同遗漏重大条款(如违约责任上限、争议解决、不可抗力等),须在分析报告中明确提出"建议增加以下条款",并草拟具体条款文本(供客户参考)。

#### 7. 审查结果整理与自检

将以上分析结论整理为:问题清单(按风险等级排序)、逐条原文引用及修改建议、建议新增或删除的条款内容、整体风险评估及谈判策略方向。输出前执行自检:

- 每处原文引用是否与合同文字完全一致(数字、日期、但书)?
- 是否遗漏条款的例外情形或前提条件?
- 跨条款关联是否已核对被引条款的实际内容?
- 所有引用是否均包含"条款序号+页码"定位?

#### 8. 修订版文书要求

本类型文书**必须生成** revised_document:按主模板「生成修改版文书」章节的修订规则与改动标记规范,输出完整的修改后合同正文(含【新增】【修改】【删除】标记)。若修订建议与现行法律法规强制性规定明显冲突,原文保留并标注【待核实】。
