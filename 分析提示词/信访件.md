### 信访类文书专属分析流程

> 本流程适用于**信访类文书**：申请人反映情况、提出建议意见或投诉请求（无特定履职指向或已穷尽法定途径），主规范为《信访工作条例》（2022年5月1日施行）。文书性质识别与入口分流已在上游完成，本流程直接进入审核。
> 〔审核顺序〕**审核流程（实体审核 → 案卷审核）→ 风险与建议 → 答复文本审核与标红修改稿**，依次执行，不得跳步。
> 〔体例标注〕〔明确规定〕＝规范明确、几无裁量空间；〔存在争议〕＝规范或裁判尺度不统一，须个案权衡；〔审核动作〕＝本条应执行的核对／留痕动作。
> 文中 `{today}` 为占位符，审核时替换为**审核当日日期**。

---

#### 一、审核流程

##### （一）实体审核要点

###### 〔审核动作〕1. 基本规范：《信访工作条例》

2022年2月25日中共中央、国务院发布，**2022年5月1日施行**，共六章五十条；国务院2005年《信访条例》已按法定程序废止。适用于党的机关、人大机关、行政机关、政协机关、监察机关、审判机关、检察机关以及群团组织、国有企事业单位等（第二条）。

〔审核动作〕2022年5月1日之后出具的任何文书，均应改引《信访工作条例》并以「条、款、项」定位。

###### 〔审核动作〕2. 提出与受理

- **形式**（第十七条）：信息网络、书信、电话、传真、走访；一般应当采用**书面形式**并载明姓名（名称）、住址和请求、事实、理由（第十九条）。
- **走访规则**（第二十条）：应当到有权处理的**本级或者上一级**机关、单位设立或指定的接待场所提出；涉及诉讼权利救济的信访事项应当按照法定程序向政法部门提出；多人走访推选代表，**代表人数不得超过5 人**。
- **转送交办**：信访部门收件后**15 日内**转送、交办（第二十二条）；其他机关收到信访人直接提出的信访事项，能够当场告知的当场书面告知，不能的**15 日内**书面告知接收情况及处理途径；不属于职权范围的告知向有权机关提出（第二十三条）。
- 已经受理或正在办理的，在规定期限内向上级再提同一事项的，**上级不予受理**（第十九条第三款）。

###### 〔审核动作〕3. 办理：诉访分离与分类处理

- **诉访分离**（第二十八条第二款）：将涉及民事、行政、刑事等诉讼权利救济的信访事项从普通信访体制中分离，由政法部门依法处理；涉法涉诉信件转送同级政法部门（第二十二条第二款）。
- **申诉求决类事项分类处理**（第三十一条）：①应通过审判机关诉讼程序或复议程序、检察机关刑事立案或法律监督程序、公安机关法律程序处理的，按法定程序处理；②应通过仲裁解决的，导入仲裁程序；③可通过党员申诉、申请复审等解决的，导入相应程序；④可通过行政复议、行政裁决、行政确认、行政许可、行政处罚等行政程序解决的，导入相应程序；⑤属于申请查处违法行为、履行保护人身权或财产权等合法权益职责的，依法履行或者答复；⑥不属于以上情形的，听取陈述、调查核实后出具**信访处理意见书**。

###### 〔审核动作〕4. 期限与三级终结

| 环节 | 期限 | 依据 |
|---|---|---|
| 受理告知 | 15 日内书面告知（能当场告知的当场） | 第二十三条 |
| 办理（第三十一条第六项事项） | 受理之日起60 日内办结；情况复杂经批准延长，延长期限不超过30 日并告知理由 | 第三十四条 |
| 复查 | 收到处理意见之日起30 日内请求上一级机关复查；复查机关30 日内提出意见并书面答复 | 第三十五条 |
| 复核 | 收到复查意见之日起30 日内请求复核；复核机关30 日内提出意见 | 第三十六条 |
| 终结 | 对复核意见不服仍以同一事实和理由提出投诉请求的，各级信访部门和其他机关、单位不再受理 | 第三十六条第三款 |

〔审核动作〕对照当前日期 `{today}` 计算：**受理日、法定届满日、实际剩余／逾期天数**。**若已超期，须明确标注逾期天数及法律后果。**

###### 〔审核动作〕5. 禁止行为与法律后果

- **信访人禁止行为**（第二十六条）：非法聚集围堵冲击机关、拦截公务车辆、堵塞交通，携带危险物品，侮辱殴打威胁工作人员，滞留滋事，煽动串联胁迫等；滋事扰序、缠访闹访情节严重的依法治安处罚直至追究刑事责任（第四十七条）。
- **不得打击报复**信访人（第十八条第三款）；不得将检举揭发材料转给被检举人（第三十条第三款）。

###### 〔审核动作〕6. 履行期限与救济告知的勾稽

〔审核动作〕信访件答复文书必须同时具备**实体答复**与**救济告知**两项，缺一即为可被复查、复核纠正的瑕疵：

- 出具**信访处理意见书／答复意见书**的，告知「自收到本处理意见书之日起30 日内向津南区复查委员会申请复查」，不得告知行政复议、行政诉讼；
- 导入**履职程序**作出履职答复的，告知「60 日内申请行政复议、6 个月内提起行政诉讼」。

##### （二）案卷审核

> 本部分以申请和答复所涉的资料为依据，解决「答复文书本身合法」之外的问题。**审核对象不止答复文本，还包括卷内要件与留痕。**〔审核动作〕逐卷比对下列各项。

###### 1. 卷内要件清单

| 序号 | 要件 | 功能 | 审核要点 |
|---|---|---|---|
| 1 | 天津市人民群众信访登记表／信访件基本情况登记表 | 固定来件要素与**期限起算** | 编号、形式、姓名、登记时间、**限办时间**、内容分类、投诉内容是否齐备 |
| 2 | 受理告知书／联系单 | 告知受理与办理期限 | 是否在收到之日起15 日内书面告知 |
| 3 | 补正告知书 | 内容不明确时一次性告知补正 | 是否及时一次性告知 |
| 4 | 延期告知书 | 延长答复期限并书面告知 | 文号、日期是否填全；延长理由与届满日 |
| 5 | 不予受理告知书 | 不属职权范围时分流 | 是否**逐项**指明受理机关与依据条款 |
| 6 | 调查核实材料（科室回复、现场定位、询问笔录、座谈会记录、会议记录） | 证明调查核实过程 | 是否有具体时间、经办人、结论 |
| 7 | 信访事项处理意见书／答复意见书／处理结果告知书 | 实体答复（条例第三十一条第六项） | 诉求逐项回应＋复查告知 |
| 8 | 依法履职答复书／行政履职答复书（网答、访答、电答字号） | 导入履职程序的答复 | 规范依据到条、款、项；复议前置告知 |
| 9 | 办理情况报告（台信报字号） | 向区信访办／督查机构报告 | 三段式：信访人基本情况、调查情况及处理意见、信访程序履行情况 |
| 10 | 息诉罢访承诺书 | 固定当事人意思表示 | 事项范围、签名、日期 |
| 11 | 律师审核意见 | 内控法律审核 | 送审人、收到日期、文书名称及文号、审核结论、签名日期 |
| 12 | 证据目录／材料目录 | 卷内清单 | 序号、材料名称、页码与实际件数一致 |
| 13 | 送达凭证（送达回证、EMS底单、签收记录、工单编号） | 固定送达日与救济期限起算 | 受送达人、送达方式、日期、签收签名 |
| 14 | 文书底稿与定稿（「（修改）」前缀稿） | 证明审核与修改过程 | 修改稿与定稿的差异是否已落实 |
| 15 | 上级转办／督办材料 | 说明案件来源与办理方式 | 转办文号、限办日期 |
| 16 | 与申请人沟通留痕（通话录音、微信、照片、视频） | 证明告知与沟通 | 是否归档并注明时间、对象 |

###### 2. 要件完整性审核（勾稽链）

〔审核动作〕按下列链条逐环核对，任一环缺失即在风险意见中标明：

1. **起算环**：登记表「登记时间／限办时间」→ 受理告知日期 → 答复文书落款日期。**审核时须核验起算口径是否一致**，避免不同文书中同一事项的起算日互相矛盾。
2. **程序环**：受理告知 → （补正／延期告知） → 调查核实 → 处理意见 → 送达。此时须核对**补正期间是否不计入答复期限**及其书面告知。
3. **实体环**：诉求逐项回应 → 事实与依据对应 → 规范条款到条、款、项。
4. **救济环**：处理意见书→复查／复核；履职答复→复议前置＋诉讼。**两类文书两种告知，不得错配。**
5. **内控环**：送审（送审单／邮件）→ 律师审核意见（载明文书名称及文号）→ 定稿 → 用印 → 送达 → 归档。
6. **证据环**：以「不予受理」「不属职权范围」结论的，必须有调查核实材料或证据支撑，并**在答复中说明事实与依据**。

###### 3. 常见瑕疵与纠正

〔审核动作〕下列问题均应作为「必改项」逐项标注：

| 瑕疵类型 | 纠正要求 |
|---|---|
| 救济告知缺失 | 补载「自收到本处理意见书之日起30 日内向津南区复查委员会申请复查」 |
| 文号空缺未填 | 发文前填全文号并核对与登记簿一致 |
| 定稿日期未定 | 删除备选、固定落款日期 |
| 文字讹误 | 校核文字，签发前通读 |
| 括号体例不规范 | 公文文号年份应用六角括号〔〕 |
| 引用已废止规范 | 2022年5月1日后一律改引《信访工作条例》 |
| 引用条文不精确 | 定位到条、款、项 |
| 调查留痕不足 | 附调查核实材料（科室回复、现场定位、询问笔录等），并在审核意见中载明「基于经办人提供事实及调查材料」 |
| 送达留痕不足 | 补送达回证或 EMS 底单、签收记录，固定救济期限起算 |
| 对上回复替代对申请人答复 | 卷内另附对申请人的答复文书或渠道反馈记录 |
| 复查复核被退回 | 首次出具即按三段式载明事实、依据与程序履行情况，避免重新出具 |
| 以信访答复代替履职答复 | 导入履职程序的，须出具依法履职答复书，不得以信访处理意见书代替 |

#### 二、风险与建议

> 对每一审核项标注「**明确规定**」（无裁量空间，违反即违法）或「**存在争议**」（规范或裁判尺度不一，须个案权衡），据此形成风险提示与建议。

##### （一）规范属性与审核意见

| 事项 | 属性 | 审核意见 |
|---|---|---|
| 信访受理告知15 日、办理60＋30 日、复查复核各30 日、三级终结 | 明确规定 | 《信访工作条例》第二十三条、第三十四条至第三十六条。期限为硬性规定，违反将被督办、追责（第四十四条、第四十五条） |
| 走访应到有权处理的本级或上一级机关、代表不超过5 人 | 明确规定 | 《信访工作条例》第二十条 |
| 履行期限＋救济告知的双项齐备 | 明确规定 | 库内存在救济告知缺失实例，属可直接纠正的瑕疵 |
| 不得以信访答复代替依法履职 | 明确规定 | 国信发〔2017〕19号第十五条；中办国办信访工作法治化意见重申。以此为由申请复查复核纠正分类错误是有效路径 |
| 信访处理意见的可诉性 | 存在争议 | 通说认为信访处理意见、复查复核意见不属行政诉讼受案范围；但信访办理中另行作出的行政行为（履职答复、补偿决定）可诉，「信访终结」不阻断对独立行政行为的救济 |

##### （二）风险提示与处理建议

- 按高风险／中风险／低风险分级。涉及期限的，须以当前日期 `{today}` 为基准显式计算（例如：当前日期 {today}，法定办结届满日 Y，剩余 Z 天／已逾期 Z 天）。
- **信访人视角**：诉求不明确的补正建议；请求复查复核（30 日）；依法转入诉讼、复议或履职申请途径；证据保全与提交凭证留存。
- **机关视角**：补正受理与告知程序、完善依据与逐项回应、规范送达留痕、防范逾期不作为风险；对实为履职请求的事项**导入履职程序**「依法履行或者答复」，不得以信访处理意见代替；发现分类错误的，依国信发〔2017〕19号第十五条撤销并重新处理或变更。

#### 三、答复文本审核与标红修改稿

〔审核动作〕完成前述审核后，以本流程所列规范为依据，对**被审文书（信访事项处理意见书、答复意见书、受理告知书、不予受理告知书等）**逐项比对并出具标红修改稿；无被审文书的，直接生成可以直接使用的答复文本。

1. **比对维度**：文书性质定性是否正确 → 引用的依据条款是否现行有效、是否准确（条、款、项） → 程序期限是否在法定期间内 → 答复类型是否适用正确 → 救济途径告知（复查告知／复议前置告知）是否完备 → 事实与请求是否逐项回应。
2. **标注方式**：**修改／新增处标红**；**删除处用红色删除线**；每处修改**注明修改依据（规范名称＋条款＋来源）**。
3. 核对信息的**名称、文号、制作时间、载体形式**等要素是否具体明确；不明确的，适用补正程序。
4. 核对是否**留存提交凭证**（收件登记、EMS底单、信访件编号等），以便固定受理日与期限起算点。
5. **待填数据**：金额、案号、证号、日期、签章等**客观数据以蓝色标注**，标明「待办案机关回填」，**不得由审核人臆造**。
6. **文本校核**：发文前必查——文号是否填全（含六角括号〔〕）、落款日期是否唯一确定、有无重复字词、「（修改）」稿的意见是否已落实、附件与正文所述材料是否齐备。
7. **输出**：修改稿与「风险与建议」意见表一并提交，并附**审核意见**。

##### 审核意见出具体例

〔审核动作〕审核意见与修改稿同步出具，**不得以修改稿代替审核意见**。体例固定为「**收到日期—送审单位—送审文书名称及文号—审核基础—审核结论—律师签名及日期**」。

> 信访事项审核意见
>
> 【收到邮件日期】，法律顾问收到【行政机关】送审的【申请文件名称及文号】。
>
> 答复书名称及答复中告知信访人享有行政复议和行政诉讼的权利，为信访部门统一要求。律师仅就答复书中对信访事项的答复内容进行法律审核，意见如下：
>
> 该答复书中对信访事项的答复内容不违反法律规定，具体事实由经办人确定。律师已审核。
>
> 律师：　　　　　　【日期】

〔审核动作〕出具审核意见时必查：1.送审文书名称与**文号**是否与卷内定稿一致；2.审核基础是否载明（经办人提供的事实、调查材料等）；3.结论是否可执行（区分答复／补正／重新出具）；4.签发日期不得早于送审日期。

##### 修订版文书要求

本类型文书为可修订类型：如发现需要修改之处（诉求表述、受理与办理程序的告知、处理意见的依据与逐项回应、复查复核与救济途径告知等），按上述标注方式输出修改后文书正文（含【新增】【修改】【删除】标记，删除处标红色删除线），每处修改注明修改依据（规范名称＋条款）；客观数据以【待核实】标注，标明「待办案机关回填」，**不得臆造**。若无需修改，revised_document 设为 null。
